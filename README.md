# Tela Live V7

Correções do sistema de salas:
- Criador entra automaticamente na sala recém-criada.
- Sala pública não pede senha ao criador.
- Sala privada usa automaticamente o código informado na criação.
- Validação de nome e código de sala privada.
- Ao trocar de sala, o usuário é removido corretamente da sala anterior e da lista de broadcasters.
- Mantém multistream e áudio com cancelamento de eco/supressão de ruído.
