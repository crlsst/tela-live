# Tela Live V12

Versão refeita da camada de salas e WebRTC.
- salas públicas e privadas com senha;
- criação de sala com entrada automática;
- múltiplas transmissões simultâneas com conexões de tela de entrada/saída separadas;
- negociação WebRTC e fila de ICE;
- call com cancelamento de eco, supressão de ruído e ganho automático;
- áudio de compartilhamento quando o navegador permitir;
- 720p/60, 1080p/60, 1440p/60 e 4K/60;
- chat e lista de participantes.

STUN está configurado. Para redes muito restritivas, adicione TURN.
