# Tela Live V8 Audio Fix

A transmissão de tela agora captura também o áudio do sistema/aba quando o navegador disponibiliza essa opção. O áudio recebido é reproduzido pelos espectadores. O preview local continua mudo para evitar retorno.

A voz continua em uma conexão separada com cancelamento de eco, supressão de ruído e ganho automático.

Ao compartilhar a tela, marque **Compartilhar áudio do sistema/aba** no diálogo do navegador para transmitir o som.
